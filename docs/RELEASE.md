# 版本说明

## 1.1.1 — 图标与返回操作优化

应用菜单统一采用圆润渐变图标，设置改为八齿金属齿轮，Home Assistant 使用青蓝色房屋与连接节点。三个游戏新增战机、羊羊叠牌和彩色方格图标，音乐封面和 Home Assistant 占位页同步更新。

返回按钮由 32×30 扩大为 54×40，箭头加粗，点击面积增至原来的 2.25 倍。音乐页和天气预览同步采用新按钮，调整菜单、游戏工具栏及预览标题布局，避免内容重叠。

这是界面维护版本；Home Assistant 仍为开发中入口。升级沿用 1.1.0 分区布局并保留 NVS 与 SD 文件。验证范围见 [1.1.1 验证记录](VALIDATION_UI.md)。

## 1.1.0 — USB 传文件

新增位于 Home Assistant 前方的独立 USB 应用、原创图标和统一风格界面。开启前说明音乐/语音停止、SD 暂交电脑、60 秒未连接自动返回及安全弹出要求，用户确认后才执行切换。

标准 MSC 仅暴露 SD 卡；本机文件访问与电脑独占互斥，安全弹出后自动恢复本机访问和原生 USB 调试。增加传输状态、读写计数、读写失败提示、未连接超时以及烧录脚本保护。独立 CH340 烧录保留。修复验证中发现的 SD 全局释放误重置 BOOT 引脚问题，按实际卡槽释放。

升级保持原分区布局，不擦除 NVS 或 SD 文件。1.0.0 标签和发布包保留。详见 [USB 说明](USB_TRANSFER.md)、[本次验证与边界](VALIDATION_USB.md) 和 [新增截图](../validation/1.1.0/index.html)。

## 1.0.0

本版本面向立创实战派 ESP32-S3 V1.0.1，16 MB Flash、8 MB PSRAM、320×240 横屏。

## 功能范围

天气与时钟、两页应用菜单、GPT Voice、SD 音乐、图片浏览、文件管理、三个小游戏、显示与声音设置、Wi-Fi、BLE 基础扫描与免输入配对、临时网页配置、BOOT 背光开关。

Home Assistant 是明确标注“开发中”的预留入口，不包含设备控制。BLE 不包含经典蓝牙音箱协议、密码输入配对或 GATT 业务服务。播放器显示已播放时间，不包含总时长、进度拖动或专辑封面解析。背光关闭不进入低功耗休眠。

## 本次审查修复

- 修复音乐暂停后停止不能返回空闲状态，影响文件释放与 SD 卸载的问题。
- WAV 解析使用有界 RIFF/PCM16 校验，支持扩展 fmt 与奇数长度元数据，拒绝损坏、截断、零通道、非法位深等输入；播放严格止于 data 块。
- MP3 识别兼容带 CRC 的 MPEG 1/2/2.5 Layer III 头。
- 当前日期、星期、时间的明确问句由设备直接调用校准时钟工具，避免模型猜测。
- 配置持久化按字段合并并串行写入，避免网页保存覆盖同期音量、亮度或城市修改；相同配置不重复写入。
- 限制 HTTP 响应并记录溢出状态，禁止自动重定向携带凭据。
- BLE 切换等待原连接断开，安全配对只接受选中的设备，忽略旧连接断开事件。
- 文件浏览器同步实际回退目录，长按文件夹后隔离松手事件，避免误触新页面，也不吞掉下一次点击。
- 串口工具保留控制线状态，支持设备截图、真实 LVGL 输入注入和 BOOT/复位验证。
- 修复播放器空闲时仍显示“正在播放”、Wi-Fi 重连空密码覆盖旧密码、长路径文字覆盖列表和重命名冲突提示不准确。
- 图片按内容验证格式与尺寸，从有界内存缓冲解码，兼容大写扩展名和 `.jpeg`，避免长路径被标准驱动截断。
- SD 目录读取失败不再发布空列表或异常条目；总线频率设为 10 MHz，提高当前板卡组合的信号余量。
- 统一固件、设备信息及搜索客户端版本为 1.0.0。

保留此前验证过的语音分片接收、有界队列、打断、自动恢复、短回复、新闻概览与来源分离、音乐退出语音后的功放恢复及 BOOT 消抖逻辑。

## 安装与数据

发布固件仅包含 bootloader、分区表和应用，不含 NVS、Wi-Fi 密码、API Key、个人录音、SD 文件或整片 Flash 备份。现有相同分区布局的设备升级时保留 NVS，禁止使用 erase_flash。

见 README 的构建与烧录命令，以及本目录下最终验证记录。联网语音和新闻依赖用户账户、网络及第三方服务，60 字短回复为模型指令，非机械截断。
