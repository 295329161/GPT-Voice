# 1.0.0 代码审查与功能检验

日期：2026-10-07（北京时间）。目标：立创实战派 ESP32-S3 V1.0.1，N16R8，320×240。审查覆盖当前项目应用、核心算法、服务、播放器本地修改、构建与诊断脚本；保留此前用户确认的语音和界面修复。

本次采用源码审查、ASan/UBSan 主机测试、实机串口诊断、真实 LVGL 输入事件、实际 API 查询及帧缓冲截图。当前环境没有专用 Bugbot 服务，没有把普通审查冒充为 Bugbot 结果。

## 审查中修复的问题

1. WAV 解析对非终止字符串使用字符串搜索，未验证通道/位深及数据长度，损坏文件可能触发越界读取或除零。改为有界 RIFF/PCM16 解析，验证元数据填充和 data 边界。
2. 音乐暂停后 STOP 没有转回 IDLE，文件占用阻止 SD 卸载。补全状态转移，实机验证暂停→停止→卸载→挂载。
3. MP3 文件头识别遗漏带 CRC 和 MPEG 2.5 Layer III 变体。补全识别并测试。
4. 日期问题可能只由模型回答。明确的当前日期/时间问句直接路由到 SNTP 时钟工具，实测返回正确日期与星期。
5. 配置快照全量保存可能覆盖同期其他字段。改为字段合并与串行 NVS 写入，相同配置不反复写入；当前 Wi-Fi 留空重连不再覆盖保存的密码。
6. HTTP 响应溢出未持续记录，带凭据的请求可能跟随重定向。溢出后整体拒绝，禁止自动重定向。
7. BLE 切换连接时旧断开事件可能清除新连接，安全请求没有核对 peer。改为等待关闭、匹配地址/连接 ID、只接受选中设备。
8. 文件浏览回退目录未同步；长路径文字覆盖列表；重命名冲突可能显示错误原因；长按松手会误触新页面。分别修复路径同步、文字边界、EEXIST 提示和松手隔离。
9. 页面切换可能吞掉刚产生的操作失败通知。只丢弃导航前的旧提示，保留操作结果；继续保持提示 4.5 秒自动消失。
10. 图片入口不兼容大写后缀/`.jpeg`，标准文件驱动还会截断长路径。改为有界缓冲加载，先验证 PNG/JPEG 尺寸，再按内容解码，退出时释放缓存与数据。
11. 播放器空闲仍显示“正在播放”，损坏音频的错误状态很快被停止状态覆盖。标题按真实状态更新，损坏文件给出临时通知。
12. 旧串口打开方式可能改变 BOOT/RESET 控制线。替换为保留控制线的控制台，`dev.sh monitor` 也使用同一实现。

13. 长时间实测出现一次 SD 读取 CRC 错误，随后目录缓存返回异常条目；卸载/挂载后恢复原有列表。补全 readdir/条目/stat 错误检查，失败时保留上一次有效目录并提示重新挂载；SD 总线设为 10 MHz 留出信号余量。具体根因尚不能仅凭一次错误判定，不能保证其他卡或接触条件下不再发生。

## 主机测试

13 个 C/C++ 测试程序使用 AddressSanitizer 和 UndefinedBehaviorSanitizer，另有 Python 构建暂存测试。范围包括图片尺寸/截断/渐进 JPEG 拒绝、按键消抖、搜索与日期意图、MCP 证据处理、WebSocket 分片、对话顺序、重采样、路径限制、射击/三消逻辑、姿态滤波、MP3 恢复、WAV 非法输入与读取边界；注入目录 I/O 错误、重复/非法条目和 stat 失败，确认保留上一次有效列表。

结果与构建摘要存入 `validation/1.0.0/`；每个测试结果以实际执行记录为准。构建中的第三方触摸接口弃用警告来自固定版本 esp_lvgl_port，未禁用看门狗或证书校验来通过测试。

## 已完成的实机检验

- 启动后 Wi-Fi、网络校时、SD、IMU、音频均就绪。版本页与启动日志显示 1.0.0。
- Wi-Fi 扫描与保存网络空密码重连成功，硬件复位后仍可自动连接。
- MP3 实际播放、暂停、停止；暂停后停止能卸载 SD，再挂载成功。退出语音恢复音乐后 PA 输出与引脚均为 1，DAC/麦克风回采增加，确认不能只靠 UI“正在播放”判断。
- 正常 PCM16 WAV 播放，损坏 WAV 被拒绝，任务和界面继续工作。
- 生成测试文件时发现大块 Flash 映射数据直接写 SD 后可能为零。诊断工具改用 RAM 分块并逐字节回读校验，所有图片/标记均校验成功后才参与验证；没有把损坏测试夹具当成应用解码器故障。
- 横向 PNG、竖向大写 PNG、大写 `.JPEG` 显示正常；损坏文件和大于 1 MiB 文件被拒绝。
- SD 降为 10 MHz 后连续读取目录 100 次，其中 50 次同时播放 MP3；条目、大小和顺序均与基线一致，没有再观察到 SD 错误。MP3 输出回采 mean_abs=15856/530/250，PA_EN=1。该有限时长复测不等于排除所有硬件接触或卡兼容性问题。
- 新建文件夹、长按进入详情、重命名、同名保护、取消删除及确认删除均通过，临时目录清理后保留原 SD 文件。
- 三消选牌、撤回、洗牌、重开；Color Flood 选色、暂停与重开；射击页面运行和暂停。游戏算法另由主机测试覆盖。
- 晴/云/雨/雪各昼夜场景已截图。预览未覆盖真实天气配置。
- BLE 扫描返回附近设备。没有连接未经确认归属的设备。
- 网页 GET 正常；错误配对码返回 403，非法地址/换行字段返回 400，空字段保存返回 200 且语音密钥仍可使用。
- BOOT 实际 GPIO0 按下关闭背光，保持按下不重复切换；松开再按恢复。熄屏时调整设置不点亮，恢复亮度 77%、占空比 787；熄屏后硬件复位默认亮屏，配置保留。
- 语音在熄屏时完成时钟和实际新闻检索。新闻调用 StepSearch initialize/initialized/tools/call，取得 HTTP 200 资料；概览 55 个汉字，追问 38 个汉字，天气 28 个汉字，均未朗读网址。
- 今日凌晨未找到当日新闻时，明确回复没有检索到；追问“第一条”时也说明没有可展开的新闻，没有编造结果。

## 验证边界

Home Assistant 是“开发中”占位页，不是可用的设备控制功能。BLE 配对没有合适且归属明确的外设，未做端到端配对；不支持经典蓝牙音箱、密码/数字确认配对或 GATT 业务。

页面操作通过 LVGL 指针输入验证，不能等同于用手操作每个物理触摸位置。姿态读数和算法已验证，但未覆盖所有人工持握方式。语音文字诊断确实连接真实服务、运行工具并输出音频，不能自动替代真人语音识别、各种声学条件下的打断与回声测试。本轮尝试使用电脑声卡合成语音做声学输入，但未观察到可确认的 VAD/ASR 事件，因此未将其记为语音识别或真人打断通过；电脑音量已恢复。健康探测成功也不能代替完整网络故障注入；没有将这些项目标为全部通过。

图片限基线 JPEG/PNG，单边不超过 2047、总像素不超过 1,048,576、文件不超过 1 MiB。回复长度由模型指令约束，不是强制截断。第三方服务、账户和网络变化仍可能导致查询失败；错误需要明确反馈。
