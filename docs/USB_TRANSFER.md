# USB 传文件

在第二页菜单打开“USB 传文件”（Home Assistant 前方），点击开启，阅读影响说明后确认。用支持数据传输的 Type-C 线连接电脑，SD 卡以 `GPT Voice SD / SD CARD` 出现；盘符或卷名由电脑及 SD 卡原有格式决定。

## 开启时的影响

- 停止音乐和语音会话。本机暂停 SD 音乐、图片和文件管理，避免电脑与设备同时修改文件系统。
- Wi-Fi、天气、时钟、游戏、设置和 BOOT 背光开关继续工作。
- 原生 USB Serial/JTAG 暂时变为 U 盘接口。板载独立 CH340 串口仍可记录日志；退出后恢复原生调试接口。
- 如果 60 秒内没有完成电脑 USB 枚举，自动卸载 USB 服务、重新挂载 SD 卡并回到普通模式。等待时也可点“取消连接”。单纯通电不算电脑已连接。
- 连接成功后不按空闲时间强制退出。电脑休眠造成的 USB 暂停也不会把 SD 卡交还本机，避免电脑恢复后继续写盘时发生冲突。

取消开启确认不改变播放或 SD 状态。退出传输后不自动播放音乐或重开语音，需要重新进入相应应用使用。电脑改名、增删文件后，本机重新读取目录并清除旧播放索引。

## 电脑端操作

Windows 10/11 使用系统自带 USB 大容量存储驱动，在资源管理器中复制文件，完成后右键该可移动磁盘“弹出”。macOS 在 Finder 中复制，完成后点击卷旁的弹出按钮。Linux 在文件管理器中复制，完成后对卷执行“弹出”。普通 USB 文件传输不需要安装 CH340 或 Espressif 驱动；CH340 驱动只涉及独立串口烧录/日志。

本次在 Linux 真机验证。Windows/macOS 的说明基于标准 MSC 协议，尚未在这两种系统实测。沿用现有 FAT SD 卡，不通过设备自动格式化；本机仍只播放、显示自己支持的文件类型。ESP32-S3 为 USB Full Speed 12 Mbps，实际传输速度低于现代高速 U 盘。

电脑完成安全弹出后，设备显示“电脑已弹出，可以拔线”，并恢复 SD 卡本机访问。仅关闭文件窗口或卸载卷不一定发送设备弹出指令；此时继续从电脑执行“弹出”，设备上点击“结束 USB 传输”会提示先安全弹出。

固件不保留延迟写回的 SD 数据，但电脑自身仍可能缓存文件和 FAT 元数据，所以不要以复制窗口消失或页面“当前空闲”代替安全弹出。没有完成写入就断电或拔线仍可能损坏文件系统。

Linux 命令行可用 UDisks 卸载对应 SD 分区，再调用其 Drive.Eject。不要把任意 `/dev/sdX` 当成目标，先核对 USB 型号和序列号。设备上的“结束”按钮不会强制夺回电脑仍在使用的 SD 卡。

## 烧录与恢复

先安全弹出并等待普通模式，再运行 `bash dev.sh flash-usb`；`bash dev.sh flash` 使用独立 CH340，已通过实机烧录。传输不会改写启动配置、eFuse、固件分区或 NVS，USB 只暴露 SD 扇区。构建脚本检测到该设备仍处于 MSC 模式时，会阻止烧录/调试复位以保护文件。

如果应用固件故障导致无法正常退出，可在停止电脑写入、卸载磁盘后用硬件 ROM 下载模式恢复：按住 BOOT，按一下 RESET，再松开 BOOT，使用 CH340 烧录。BOOT 的上电启动选择作用保留，RESET 不复用；无需擦除整片 Flash 或 NVS。

## 维护诊断

`page 22` 打开 USB 页面；`status` 包含 USB 阶段、电脑连接、暂停、倒计时和读写计数。`usb-on` / `usb-off` 是物理串口诊断接口，直接发出请求，不显示 UI 确认。

`usb-test-nohost` 仅用于维护测试：实际执行 SD 交接和 60 秒计时，同时保持 USB 软件断开，模拟没有主机。它不会设置持久选项；下一次普通开启恢复正常枚举。这能验证固件超时路径，不代表已经用独立充电器或不同数据线完成物理验证。
